# AI-Powered Natural Gas Pipeline Digital Twin

This independent academic project designs a simulated pipeline monitoring and engineering decision-support platform around the 296.105 km Bokaro–Angul Pipeline Odisha section. It studies gas hydraulics, linepack, synthetic telemetry, anomaly detection, compressor energy, equipment health, risk, and engineering document retrieval. The prototype uses illustrative assumptions and synthetic readings, with no access to GAIL operational systems.
